# DristiCare

## SIH 2026 - SIH26038
Explainable AI for Diabetic Retinopathy Screening in Rural Areas.

### Project Overview
DristiCare is an AI-assisted retinal screening system designed to support
early screening and referral for diabetic retinopathy in rural healthcare
settings.

### Planned Technology Stack
- Python
- OpenCV
- PyTorch
- EfficientNet / ResNet
- U-Net
- Grad-CAM
- FastAPI
- HTML, CSS, JavaScript
- MySQL / PostgreSQL
- MATLAB
- Simulink
